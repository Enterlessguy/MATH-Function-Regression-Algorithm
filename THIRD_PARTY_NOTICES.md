# Third-party notices

Function Regression is MIT licensed (see [LICENSE](LICENSE)). It has no
runtime or build dependencies and contains no third-party code.

Version 1 loaded React, ReactDOM, Babel Standalone, Tailwind CSS and KaTeX
from public CDNs. Version 2 still loaded Tailwind and KaTeX. Version 3 loads
nothing from anywhere else.

## Brand assets

`assets/cube.png` is the Intelligence Database cube. `assets/welcome.ttf` is
the "Control Center Script" face used for the startup greeting.
`assets/chevron.svg` is the select arrow. All three are original Intelligence
Database artwork, shared with I-DB Macro and the Schedule I Control Center,
and are released with this project under the same MIT licence.

## Fonts referenced by name

The stylesheet asks for system fonts by name (Segoe UI, Cascadia Mono,
Consolas, Cambria Math and others). They are not bundled. If they are
missing, the browser uses its own fallbacks.
